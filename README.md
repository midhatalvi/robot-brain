# Robot Brain Lab

A hands-on demo for first-year engineering students: build a tiny VLA (Vision, Language, Action) robot in your browser.

- **Vision:** your webcam plus an object detector (COCO-SSD, TensorFlow.js) finds everyday things like cups, phones and bottles.
- **Language:** type a command like "grab the cup".
- **Action:** a robot arm on screen moves, grips and lifts.
- **Brain:** a short JavaScript function you can rewrite yourself, or with any AI chatbot.

Open it: https://midhatalvi.github.io/robot-brain

Everything runs in your browser. No login, and no images leave your computer.

Made by Midhat Alvi for the Rutgers School of Engineering ID3EA Interactive Demos.
